# ICOPE 小幫手　安裝與使用說明

> 下載檔裡的程式叫 `IcopeTool.exe`。圖文並茂的操作教學：程式裡按 `F1`，或看 GitHub 上的 docs/GUIDE.md。
> 這是診所自己開發的輔助工具，不是國健署的官方軟體；查詢結果以國健署系統為準。

## 三分鐘安裝

1. 下載 `IcopeTool-<版本>-win64.zip`。
2. 在 zip 上按右鍵 →「解壓縮全部…」，解到 `D:\IcopeTool\` 這類可以寫入的資料夾。
3. 進入解壓後的 `IcopeTool` 資料夾，雙擊 `IcopeTool.exe`。
4. 出現「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」。
5. 在歡迎視窗選「只有這台電腦使用」，按「開始使用」。

看到左邊有「篩檢查詢、轉介衛教單、設定」三個選項的主畫面，就安裝好了。不需要安裝 Python 或任何其他軟體。下面是每一步的細節。

## 一、系統需求

- Windows 10 或 11（64 位元）
- 螢幕 1280×720 以上（建議 1366×768 以上）
- 查詢國健署資料需要能連上網際網路（只會連到 `hpdcs.hpa.gov.tw`）
- 讀健保卡需要一般的晶片讀卡機（可與 HIS 共用同一台）；沒有讀卡機也能用，手動輸入身分證字號即可
- 列印需要已經裝好的印表機；沒有印表機可以先「另存 PDF…」

## 二、下載與安裝

1. **下載**：到 https://github.com/leon80148/icope_tool/releases/latest ，在 Assets 底下點 `IcopeTool-<版本>-win64.zip`（約 130 MB）。
   - 想確認檔案沒有被動過（選做）：在下載資料夾的空白處按右鍵 →「在終端機中開啟」（Windows 10 是按住 `Shift` 再按右鍵 →「在此處開啟 PowerShell 視窗」），輸入
     `Get-FileHash .\IcopeTool-<版本>-win64.zip -Algorithm SHA256`，結果要和發佈頁面寫的 SHA-256 一樣（大小寫不拘）。
2. **解壓縮**：在 zip 上按右鍵 →「解壓縮全部…」，位置選**可以寫入的資料夾**，例如 `D:\IcopeTool\`。
   - 不要放在 `C:\Program Files`：程式預設把資料放在程式旁邊的 `data` 資料夾，Program Files 沒有寫入權限。
   - 不要直接在壓縮檔的視窗裡雙擊 exe：那樣是在暫存資料夾執行，設定不會留下來。
3. **執行**：進入解壓後的 `IcopeTool` 資料夾，雙擊 `IcopeTool.exe`。
   - 第一次執行若出現藍色的「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。這是因為程式沒有購買程式碼簽章，不是中毒；請只從上面的網址下載。
   - 防毒軟體若詢問，選擇允許。
4. **選擇資料放在哪裡**：第一次開啟會出現「歡迎使用 ICOPE 小幫手」。
   - **只有這台電腦使用**：資料放在程式旁的 `data` 資料夾（視窗上會寫出完整路徑）。大部分院所選這個。
   - **多台電腦共用**：選 NAS 或網路磁碟上的共用資料夾（見第四節）。之後也可以再改。
   - 按「開始使用」。你會看到主畫面，「篩檢查詢」上方有一張「依需要完成設定」的清單。

想放桌面捷徑：在 `IcopeTool.exe` 按右鍵 →「傳送到」→「桌面（建立捷徑）」。捷徑可以自己改名成「ICOPE 小幫手」。

## 三、第一次使用要設定的項目

開啟後「篩檢查詢」頁上方會有設定清單，**用得到的再設定**即可（也可以先隱藏）：

| 想做的事 | 需要先設定 |
|---|---|
| 只印衛教單張 | 第 4 項 |
| 印轉介衛教單 | 第 2、3、4 項，建議再做第 5 項 |
| 查詢今年能不能做 ICOPE | 第 1 項 |

1. **國健署系統帳號**（只有篩檢查詢需要）：設定 › 國健署帳號 › 設定帳號密碼，輸入 hpdcs 的帳號密碼後按「儲存並測試登入」；出現綠色的「登入成功」後按「完成」。
2. **診所與轉介單**：診所名稱、電話、地址會印在轉介衛教單上，電話會放大印在標題下方。同一頁的「各項衛教重點」可以替每個異常項目寫一段給長者的話（選填，200 字、6 行以內），會印在該項目的標題下方。
3. **轉介資源**：設定 › 轉介資源庫 › 匯入 › 從 Excel 匯入（衛生局「社區資源盤點表」格式），或下載 Excel 範本自己填；也可以先匯入嘉義市示範資料試用。
4. **衛教單張**：設定 › 衛教單張 › 加入 PDF（可一次選多個，或把 PDF 拖進視窗），再點兩下設定名稱與建議搭配的項目。
5. **院所預設**（建議做，日常會快很多）：在轉介資源庫與衛教單張選取院所固定會給的項目，按「設為院所預設」。之後製作轉介單時按「帶入院所預設」就會一次帶入。

別的院所給你「設定包」（zip）的話：設定 › 匯出／匯入 › 選擇設定包… › 合併，就能一次帶入對方的資源與單張；匯入後再到上面兩頁確認院所預設。

## 四、多台電腦共用資料

1. 在 NAS 或伺服器建立共用資料夾，例如 `\\NAS\icope\data`，並把存取權限只開給院所同仁使用的 Windows 帳號。
2. 第一台電腦：設定 › 本機設定 › 變更資料夾…，選共用資料夾。「把目前的資料複製到新資料夾（新資料夾沒有資料時）」保持勾選，這台電腦已經設定好的內容會搬過去。
3. 其他電腦：同樣到本機設定指到**同一個**資料夾。共用資料夾已經有資料，不會被覆蓋。
4. 設定、轉介資源、衛教單張、各項衛教重點、國健署帳號與登入狀態都會共用；讀卡機設定與查詢紀錄是每台電腦各自的。

**權限提醒**：國健署帳號密碼以明文存放在共用資料夾內的 `auth` 子資料夾（多台電腦要共用同一組帳密，無法用單機的加密）。安全邊界就是這個資料夾的存取權限，請不要把它開放給不相干的帳號或放在公開的分享位置。

## 五、讀卡機

- 一般的晶片讀卡機接上 USB 後，Windows 會自動裝好驅動程式；HIS 已經在用的那一台可以直接共用。
- 程式以共用模式讀卡、不會重置卡片，可以和展望等 HIS 共用同一台讀卡機；HIS 正在讀卡時稍等幾秒再按「讀健保卡」。
- 同一台電腦接了兩台讀卡機（例如健保卡與醫事人員卡）時，到設定 › 本機設定 › 健保卡讀卡機，選健保卡用的那台，再按「測試讀卡」確認。

## 六、日常操作

- **篩檢查詢**：插卡按 `F2`（或「讀健保卡」），或輸入身分證字號按 `Enter`。查詢中可按 `Esc` 取消。讀卡查詢會順便核對年齡（今年度滿 65 歲；原住民 55 歲），手動輸入則無法核對。
- **轉介衛教單**：查詢結果按「製作轉介衛教單」會帶入長者；勾選項目 → 按「帶入院所預設」→「確認與列印」→「列印」（`Ctrl+P`）。要調整內容時按「下一步」逐步選資源與單張。印完按「開始下一位長者」。
- **只印衛教單張**：轉介衛教單頁右上角按「只印衛教單張…」，勾選後按「列印」；不加首頁、不需要帳號。
- **圖文說明與快捷鍵**：程式內按 `F1`。每個步驟都有標了編號的畫面，最後有「卡住了怎麼辦」。

## 七、更新程式

1. 關閉程式。
2. 下載新版 zip，解壓後**覆蓋**原本的程式資料夾（`data` 資料夾不會被覆蓋；若資料放在共用資料夾則不受影響）。
3. 開啟程式，左下角會顯示新版本號。每一版改了什麼見資料夾裡的「更新紀錄.md」。

多台電腦共用時，每台電腦各自更新程式即可；建議同一天更新完，避免新舊版本混用太久。

## 八、備份

- 最簡單：把資料存放位置的整個資料夾複製一份（裡面含國健署帳密，備份也要放在只有同仁能存取的地方）。
- 只備份資源與單張：設定 › 匯出／匯入 › 匯出…（不含帳密、診所名稱電話地址與各項衛教重點）。

## 九、問題排除

| 狀況 | 處理 |
|---|---|
| 雙擊 exe 沒有反應 | 確認是「解壓縮全部」之後才執行，不是在壓縮檔視窗裡直接開；再確認防毒軟體沒有把它隔離。 |
| 顯示「已暫停自動登入」 | 帳號或密碼可能不正確，或帳號被停用。為避免帳號被鎖，程式不會一直重試；到設定 › 國健署帳號確認後重新儲存帳號密碼即可恢復。 |
| 連不上國健署系統 | 國健署網站可能維護或很慢，稍後重試，或按「改用國健署網站」人工查詢。 |
| 無法存取資料存放位置 | 可能是 NAS 或網路磁碟離線、共用資料夾的權限改變，或 USB 隨身碟沒插上；確認後按「重試」。「改用其他資料夾…」會換成另一份資料（原本的資源與單張不會跟過去），確定要搬家才用。 |
| 讀不到健保卡 | 確認卡片插好、晶片朝上；HIS 正在讀卡時等幾秒再試；接了兩台讀卡機時到本機設定指定健保卡那台。 |
| 列印中文字變方塊或程式異常 | 執行自我檢測（見下方），把結果資料夾提供給管理者。 |

**自我檢測**：在程式資料夾的空白處按右鍵 →「在終端機中開啟」（Windows 10 是按住 `Shift` 再按右鍵 →「在此處開啟 PowerShell 視窗」），執行

```
.\IcopeTool.exe --self-test 檢測結果
```

會檢查字型、讀卡元件、PDF 產生與預覽、驗證碼辨識、使用說明的圖片與主畫面，結果寫在 `檢測結果\report.json`（不連網、不需要帳號）。

**紀錄位置**：`%LOCALAPPDATA%\IcopeTool\logs\`（`audit.log` 只記事件與身分證雜湊碼；`error.log` 是程式錯誤）。

## 十、移除

刪除程式資料夾即可，程式不會寫入登錄檔或安裝服務。若要一併清除本機設定與紀錄，再刪除 `%LOCALAPPDATA%\IcopeTool`。共用資料夾內的資料（含國健署帳密）請依院所規定另行處理。
